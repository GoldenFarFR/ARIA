[CODE] Subject   : consult-gemini.sh mechanical citation guard -- converged to 0 false positives after 3 real-test iterations, real bug found in the audited code along the way
Date : 2026.08.03 / Problem : the manual second-opinion script (`scripts/consult-gemini.sh`, distinct from the automatic `devils-advocate-review.sh` post-push hook, same underlying OpenRouter/Gemini-call pattern) enforces a VERIFIE/HYPOTHESE citation discipline -- every factual claim must be either `[VERIFIE -- citation exacte : "..."]` (a verbatim quote, mechanically grep-checked against the real sent text) or `[HYPOTHESE -- ...]`. First real end-to-end test flagged 4, then (after a partial fix) still 6 citations as "unverified" despite being visibly correct on manual read -- three DISTINCT root causes stacked on top of each other, found one at a time across 3 more real test cycles: (1) the diff format itself (`+`/`-` line prefixes, `@@` hunk headers, `diff --git`/`index`/`---`/`+++` metadata) survived flattening and broke citations that reconstruct a comment a diff wrapped across two lines -- also the direct cause of the operator's separate readability complaint ("pourquoi tu met plein de symbole"); (2) a `<<<` here-string always appends a trailing newline, `tr '\n\t\r' ' '` turns it into a trailing SPACE, and command substitution strips trailing newlines but never a trailing space -- so both the normalized prompt and every normalized citation silently carried one extra space, breaking any citation that ends right before punctuation (e.g. citing "...= 20" when the source reads "...= 20,"); (3) Gemini escapes an embedded double-quote inside its own citation (e.g. a Python kwarg `source="direct_buy"` cited as `"source=\"direct_buy\""`) -- a naive `[^"]+` capture regex stopped at that first escaped quote, truncating the citation to garbage and flagging a fully correct citation as a hallucination; a related variant cites a multi-line source fragment using a literal two-character `\n` marker instead of a real newline, which also survived normalization untouched.
Solution : (1) upfront `awk` cleaning pass (before the text is ever sent to the API or checked) strips every diff-format marker, producing the `PROMPT_CONTENT` that both goes to Gemini and gets verified against; (2) `sed -E 's/^ +| +$//g'` trims leading/trailing whitespace on both the normalized prompt and every normalized citation, after the existing tab/newline-to-space flattening; (3) citation extraction regex changed from `[^"]+`/`` [^`]+ `` to `(?:[^"\\]|\\.)+`/`` (?:[^`\\]|\\.)+ `` (treats any backslash-escaped character as one atomic unit that never terminates the match), followed by `sed 's/\\"/"/g; s/\\n/ /g; s/\\t/ /g; s/\\r/ /g'` to un-escape the quote and any literal whitespace-escape sequences back to their real form before comparison. Verified by 3 more real OpenRouter calls (not just unit-level sed testing) -- 6 -> 3 -> 2 -> 0 unverified citations across the 4 live iterations, confirming the fix rather than assuming it from the sed logic alone. Side effect noted by the operator from the real OpenRouter Activity dashboard: stripping diff artifacts also reduces token volume sent (Gemini bills per input token), a genuine (if secondary) cost benefit on top of the readability/accuracy fix.
Real finding surfaced by this exercise, not yet acted on : Gemini's audit of commit `4a6dace8` (chasing_filter_shadow, Item #65) correctly caught (fully VERIFIE, both citations confirmed byte-for-byte against the real files) that `chasing_filter_shadow.py`'s module docstring claims "Stochastique %K (V3/V4) = 14" but `scalping_variants.py::evaluate_v4_combo` actually passes `recent_low_window=RECENT_LOW_WINDOW_BOLLINGER_VWAP` (20), not `RECENT_LOW_WINDOW_STOCHASTIC` (14) -- V4 genuinely combines Bollinger AND Stochastic signals (double confirmation), so which window it "should" use is a real, still-open judgment call, not a code crash. Non-blocking (the shadow filter only logs, never rejects a trade) but a real docstring/code mismatch to resolve before the shadow census's exit-criteria numbers are trusted.
`scripts/consult-gemini.sh`.
