[ETAT ACTUEL] Subject : DefiLlama product map + free-API verification (25/08 diligence, operator-directed after a regime-indicator discussion)
Date : 2026.08.25 / Problem : operator asked whether ARIA's per-chain "market regime" indicator (currently built only from the shadow pockets' own candidate peaks) could be cross-checked against a real market-wide volume/health signal, and pointed at DefiLlama specifically as a reference to lean on for any future market-data research. Needed a real verification of what DefiLlama actually offers for free vs paid before proposing anything.
Solution : DefiLlama ships THREE distinct products, easy to conflate: (1) the free public REST API (`api.llama.fi`, zero authentication, no key) -- 31+ endpoints covering protocol/chain TVL (historical daily series), DEX volume by chain (historical), stablecoins, yields, fees; (2) the Pro API (`pro-api.llama.fi`, $300/month) -- higher rate limits + exclusive endpoints (token unlocks, bridges, digital-asset treasuries); (3) LlamaAI -- a natural-language analytics chat tool, bundled only with the paid Pro subscription, NOT a programmable API endpoint (confirmed via WebSearch, no separate LlamaAI API documented anywhere) -- so "wire ARIA directly into their LLM" is not a real integration path; the free REST API is the actual, automatable data source, and is a better fit for a pipeline than a conversational tool would be anyway. LlamaFeed (news/tweets/prices aggregator, defillama.com/feed) is a separate consumer-facing product, not yet evaluated for a real API.
Two endpoints verified LIVE (curl, no key) on ARIA's three real chains: `GET https://api.llama.fi/v2/historicalChainTvl/{chain}` (daily TVL history -- Base: 1168 points since 06/2023, Solana: 1988 points since ~2021, Robinhood: since 07/2026 launch, all returned real non-zero current TVL) and `GET https://api.llama.fi/overview/dexs/{chain}` (DEX volume summary + full historical chart via `totalDataChart`, `total24h`/`total7d`/`change_1d` -- Base $1.39B/24h, Robinhood $644M/24h across 75 protocols). Both endpoints return the COMPLETE history in a single call -- no need to wait months to "backfill": the past is already there, only the going-forward increments need a periodic re-fetch. One real gap found: the "Normalized Volume by Chain" metric shown on defillama.com's own dashboard (wash-trading-excluded) has no equivalent free-API endpoint identified so far -- the free DEX-volume endpoint is raw, unadjusted volume, exactly the kind of number the operator's original concern (a chain's "30% of peak" reading unaffected by how many of its tokens rugged) would want filtered out.
Not yet built: no aria-core client, no persistence table, no wiring into `regime_state()`/`market_sentiment.py`. This entry is the diligence baseline a future implementation should start from -- see `docs/HANDOFF_PIPELINE_MOMENTUM.md` for the regime-indicator discussion this came out of.

[ETAT ACTUEL] Subject : LlamaAI-generated composite regime-score proposal -- cross-checked, 3 more free endpoints verified, 2 real divergences found
Date : 2026.08.25 / Problem : operator relayed a full report from LlamaAI (DefiLlama's paid chat product) proposing a composite 0-100 "market regime" score for Base/Solana/Robinhood Chain, built from 4 equally-weighted components (on-chain activity, momentum, volatility expansion, leverage buildup) mapped to a trades/hour multiplier per venue. Needed independent verification before trusting any of it, per this project's own "verify before asserting" doctrine -- a third-party LLM report is exactly the kind of claim that doctrine exists for.
Solution : the 2 TVL figures already verified (05/08 entry above) matched the report's table (Solana $5.81B, Base $5.58B). Verified 3 MORE free endpoints live: `GET /overview/fees/{chain}` (Base $2.75M/24h, Robinhood $3.06M/24h, Solana $14.41M/24h, all free, no key) and stablecoin coverage confirmed for all 3 chains via `GET https://stablecoins.llama.fi/stablecoinchains`. **Two real divergences found from the report's own claim that its 6 signals are "100% measurable, no interpretation"**: (1) `GET /overview/derivatives` (the report's cited path for aggregate Open Interest) returns `"Upgrade to the paid API plan"` -- NOT free, contradicting the report's own free-tier framing; the actually-free equivalent is `GET /overview/open-interest` (verified, returns real aggregate OI, $23.38B), a different path than what the report implied. (2) The "Normalized Volume by Chain" gap from the entry above still stands -- the report's own "on-chain activity" component uses raw DEX volume, the same wash-trading-unfiltered number already flagged, despite the operator's original concern being precisely about a rug-distorted reading.
The composite score itself (25/25/25/25 weighting, regime bands, trades/hour multiplier) is presented by its own author as "a starting methodology, not an absolute truth" -- appropriately hedged, but genuinely untested: a real backtest against ARIA's own archived shadow closures (194 Base / 122 Robinhood / 135 Solana, archived same day as `*_archive_reset_20260825`, see `docs/HANDOFF_PIPELINE_MOMENTUM.md`) was considered but NOT run -- only 3 distinct days of history exist post-reset, nowhere near enough to validate a composite score's weighting per this project's own n/outlier doctrine. Revisit once more days of shadow data accumulate.
Not yet built: same gap as the entry above -- no aria-core client, no persistence, no wiring. A list of precise follow-up questions for LlamaAI (methodology rigor, wash-trading filtering, Robinhood Chain data-maturity threshold, real data latency) was prepared the same session for the operator to relay.
